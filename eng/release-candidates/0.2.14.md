## Changes

- Fixes a startup failure when a valid settings library grows beyond the microphone helpers' 64 KiB read limit. The capture host and mute controller now read a small, separately maintained runtime-preferences file rather than the dashboard's profile library. This also preserves the selected mute-following opt-out instead of silently falling back to the default policy. Existing settings remain intact.
- Records bounded, privacy-safe process lifecycle and pipeline progress metadata: microphone-host starts/exits, capture levels, recognized-character counts, translation timing and queued-chat counts. These records contain no audio, recognized words, translations, device names or People data.
- Distinguishes capture-host, controller and relay failures. Known exception categories, HRESULTs and native error codes remain available in the support report without raw exception text, paths or endpoints. Ambiguous legacy failures are labeled as ambiguous rather than assigned to the wrong process.
- Adds a Save support report action with read-only local dependency/connection checks and safe current settings metadata. Failure snapshots are kept locally so a report can retain the last failed attempt. Reports are saved on the user's device; nothing is uploaded automatically.
- Adds regression coverage for large settings libraries, safe report content and runtime event parsing. A CPU-only test of the pinned native recognizer passed eight speech cases; that result does not certify a different GPU/Vulkan setup or the reporting friend's Windows 10 installation.

## Included files and verification limits

This unsigned Windows x64 preview includes its matching GPL-3.0-only corresponding source, third-party notices, licenses and SHA-256 checksums. Promotion verifies the successful hosted candidate's existing bytes; it does not rebuild them or execute the installer.

Windows 10 native workflows target version 1809 and newer. Optional Linux/GPU speech and application-specific subtitle capture retain separate system requirements. Hosted builds, isolated fixtures and the CPU recognition test do not certify every fresh-PC installation, GPU, live translation session or Windows 10 configuration. The remaining failure on the reporting friend's PC has not been reproduced or established from the available evidence; the new report is intended to expose the failed stage without repeated troubleshooting questions.
