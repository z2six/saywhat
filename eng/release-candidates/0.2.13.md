## Antivirus review status

Bitdefender flagged the predecessor, **0.2.11**, as **Gen:Variant.MSILHeracles.276181**. That review submission remains pending. No vendor clearance has been received for **0.2.13**, and its actual detection status has not been established. This release does not claim that 0.2.13 is currently flagged or cleared.

Keep antivirus protection enabled. If security software blocks the download or installation, wait for the vendor review.

## Changes

- Corrects a 0.2.12 image-preparation bug: a text conversion corrupted binary Linux file-capability attributes, causing errors such as `gst-ptp-helper: Cannot restore extended attributes: security.capability`. The prepared image omits only the three file-capability tags on bundled helpers that speech does not use. Other metadata and file contents are preserved; graphical integration remains disabled before first boot.
- Failed imports remain untouched. Retrying setup prepares a separate app-owned component rather than booting an incomplete import.
- Prevents temporarily locked or unwritable controller, capture-host and OSC-relay logs from stopping voice translation, chat forwarding or a verified mute-state change. Redirected-output I/O failures no longer abort capture turns or OSC forwarding either. Available diagnostic sinks retain status; unknown VRChat mute state still pauses capture when mute-following is enabled.
- Native Windows speech recognition remains available without Linux or Remote Desktop components. Existing saved model and language choices are preserved.

## Included files and verification limits

This unsigned Windows x64 preview includes its matching GPL-3.0-only corresponding source, third-party notices, licenses and SHA-256 checksums. Promotion verifies the successful hosted candidate's existing bytes; it does not rebuild them or execute the installer.

Windows 10 native workflows target version 1809 and newer. Optional Linux/GPU speech and application-specific subtitle capture retain separate system requirements. Hosted builds and isolated fixtures do not certify every fresh-PC installation, GPU, live translation session or Windows 10 configuration. Real Windows 10 and fresh-PC acceptance testing remains outstanding. These fixes address the verified import defect and a controller failure found in an earlier log; they do not establish the cause of any unlogged missing chat messages.
