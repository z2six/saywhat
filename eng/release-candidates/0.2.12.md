## Changes

- Fresh own-voice and subtitle setups choose native Windows Nemotron recognition. Existing saved recognition choices are preserved.
- Optional Voxtral setup prepares a verified Ubuntu image with desktop integration disabled before its first launch. Import receipts bind the owner, exact WSL registration, storage path and completed import. Interrupted or replaced components are preserved while a separate component is prepared safely.
- Completed legacy or externally imported Linux speech installations are preserved, not migrated to the new headless layout. They can still invoke their existing desktop integration. Choose a native Windows recognizer to avoid that dependency; this update does not repair Windows Remote Desktop components.
- Speech setup checks free space on the Windows drive backing its Linux storage. Linux package setup has headless input, protected progress output, bounded lock waiting and recovery for an interrupted package transaction. CUDA preparation checks driver compatibility before downloading the toolkit.
- Model and runtime downloads have response and inactivity deadlines, explain their single transient retry, and preserve cancellation and checksum verification.
- The installer accepts Windows 10 1809 and newer for native preview workflows. Optional WSL/CUDA paths have separate Windows and driver requirements. Process-specific subtitles still require the Windows 11 capture API; Windows 10 users must explicitly choose All playback.

## Included files and verification limits

This unsigned Windows x64 preview includes its matching GPL-3.0-only corresponding source, third-party notices, licenses and SHA-256 checksums. Promotion verifies the successful hosted candidate's existing bytes; it does not rebuild them or execute the installer.

Hosted builds and isolated fixtures do not certify every fresh-PC installation, GPU, live translation session or Windows 10 configuration. Real Windows 10 and fresh-PC acceptance testing remains outstanding.
