# SayWhat? 0.1.14 preview

## What’s new

- The default sentence-ending pause is **1.2 seconds of microphone silence**. Custom timing settings are preserved.
- **Show translations while I speak** can send early translations using the sentence heard so far, followed by the completed sentence. These are submitted chat bubbles, not keyboard drafts, and do not open VRChat’s keyboard.
- Improved recovery after a failed speech turn so the next sentence is not discarded.
- Long chat messages stay within VRChat’s display limits while recognition keeps the full sentence as context.
- A manual **Check for updates** option in Settings.

Early messages are spaced by at least 1.5 seconds. You can turn them off in Settings to translate only completed sentences. The pause setting is not a promise of an on-screen message within 1.2 seconds: recognition, translation and GPU use add delay.

## Preview limitations

This installer is unsigned. Fresh-PC installation, hardware compatibility, live accuracy and long-session performance still need testing. Optional speaker recognition can confuse music or overlapping voices; it does not separate simultaneous speakers.

The installer, complete ZIP, matching **SayWhat-Corresponding-Source.zip**, licenses and checksums are provided together. GitHub’s automatic “Source code” archives are not the application source. SayWhat?’s original contributions use GPL-3.0-only; third-party terms remain separate.
