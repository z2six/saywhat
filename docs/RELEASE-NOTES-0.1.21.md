# SayWhat? 0.1.21 preview

First-time setup now has its own step-by-step screens.

- Choose the app language, theme and translation languages.
- See a translator suggestion based on a local hardware check. Hardware details are not uploaded, and the check does not load models.
- Review downloads and any Windows permission/restart requirements before preparing translation. See actual download and installation progress.
- Follow a short, skippable tour: Help first, then your voice, subtitles and Settings.

Already set up? Open **Settings → Run setup again** to try the new flow. Your downloaded files and saved people are kept. Canceling or failing a rerun does not replace your working translation choices. Other translation models and advanced settings remain available in the main app.

The setup and tour support English, Simplified Chinese, Japanese and Korean, and follow the selected theme. Setup never starts translation automatically: choose Start on Home when you are ready.

Subtitles also have a **?** button for a quick guide, with a one-time offer when you first open them. It explains translated messages, optional speaker recognition and choosing a saved name to improve future matches. The guide links directly to the recognition on/off control in Settings. Reading or closing it leaves translation running.

Windows 11 x64 unsigned preview. Download the Setup executable to install or update. Matching GPLv3 source and the complete distribution with licenses are available alongside it. Models are downloaded during setup, not bundled in the installer. Verification uses offline fixtures and UI previews; fresh-PC installation still needs user acceptance testing.

The new **People** section brings your saved names, photos and voice examples together. Add or find a person, change their photo and see their translation count. Their photo also appears in subtitle messages; missing photos show initials. Photos are reduced to small local copies without location metadata, and the original picture is not changed or uploaded.

Translation counts start with this update and count completed subtitle messages once. Recent name corrections move the message's count to the right person. Voice familiarity describes clear examples saved for the current recognition model, not a measured accuracy percentage. Recognition stays optional.

In-app updates now download and verify the installer, show installation progress, preserve your settings and models, and reopen SayWhat? with translation stopped. Choose **Update now** to approve; Windows may still ask for administrator permission. If a safe automatic reopen is unavailable, setup tells you to open the app from Start. Manual setup still offers its normal install/update/uninstall choices.
