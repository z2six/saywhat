SayWhat? 预览版

SayWhat? 是非官方 VRChat 语音翻译工具，并非由 VRChat 制作或认可。

支持安装到 Windows 10 21H2（内部版本 19044）及更新版本，或 Windows 11，需为 x64。自己的语音转 VRChat 聊天默认使用 Windows 原生工具。Windows 10 兼容性仍处于预览阶段，尚未在真正的 Windows 10 电脑上验证。

仅监听 VRChat 或指定应用的字幕需要 Windows 11。在 Windows 10 上，可以主动选择“全部播放音频”，但它也会听到其他应用的声音。应用不会自动切换到这一更宽的录音范围。

开始使用

默认只为当前用户安装，也可以选择为所有用户安装共享应用文件；Windows 会请求管理员权限。即使供所有用户使用，可选的数据操作也只影响已验证的发起账户，其他账户的数据全部保留。如果无法验证身份，或使用其他管理员账户且无法使用原始用户身份，清理将被禁用；请从您自己的账户正常启动安装程序。

安装程序可更新、修复或卸载已注册的应用。你的数据默认保留。已验证账户的操作提供三个独立、默认未选中的选项：重置偏好、移除已保存的说话人和翻译日志、删除应用缓存中的已下载模型。全部不勾选即可在卸载时保留所有数据。最后确认默认选择“否”。仅删除已知的缓存文件；缓存外导入的文件、其他模型库及 Windows 语音支持均保留。清理失败会明确报告。

安装结束时可以选择打开 SayWhat?，此选项默认勾选。打开应用不会启动翻译。手动发起的静默安装不会打开应用。从应用发起并通过验证的更新可在安装成功后自动重新打开 SayWhat?，翻译保持停止；如果无法自动打开，请从“开始”菜单打开。安装时选择的语言是新用户的界面默认语言，不会更改翻译目标；已保存的界面语言优先。在应用中可随时更改界面语言。

首次打开后，选择你的语言并运行“设置 SayWhat?”。所选模型需经同意后下载，不包含在安装程序中。建议先使用较小的 Hy-MT2 1.8B；7B 是可选的大模型。设置可请求权限或重启；重启后打开应用并继续设置。完成设置后翻译仍为停止状态。

默认的 Nemotron 语音识别直接在 Windows 上运行，无需 WSL、LM Studio 或另一款翻译应用。FireRedASR2 字幕也使用 Windows 原生工具。可选的 Voxtral 和 Groups 语音功能使用应用管理的 WSL2 Ubuntu，可能需要权限、重启和额外下载；兼容性取决于所选引擎和硬件。Microsoft Visual C++ 必需组件直接从 Microsoft 下载，并核对校验值与签名；适用 Microsoft 条款，不会自动重启。

隐私与退出

语音及翻译在本机处理，不上传语音、姓名或声音指纹。联网用于设置下载，而非云翻译。说话人学习保存本地声音指纹，不保存音频；日志可能包含对话，请分享前检查。说话人识别仍可能出错，不能实时分离同时讲话的多个人。

关闭主窗口时可以退出并停止工具，或保留在托盘运行。仅退出会释放此应用拥有的模型与进程，不会退出 VRChat 或卸载其他应用的模型。更新与卸载会等待应用安全退出；不会强制结束正在运行的工具。

此预览版未签名，尚未在全新电脑上完整验证。速度、准确度和长时间运行仍需测试。附带对应源码与第三方许可；软件许可页使用英文原文。
